# Frozen historical diagnostic: hourly decision time

Recorded before computing any new time-window counterfactual PnL. This is a shadow replay of already SHA256-verified Limitless/Binance public archives, not a new collection or a production rule. The old October 6 holdout has been repeatedly inspected, so none of these windows can gain independent holdout status.

1. Compare exactly four fixed time offsets from hour opening: **5, 15, 30 and 45 minutes**. A condition belongs to the same discovery/old-holdout phase and UTC-hour cluster as the original hourly-v1 ledger. Use all 162 existing condition IDs; two unresolved outcomes remain unscored. Do not search more minute offsets, gate thresholds, symbols, or PnL-optimal weights in this test.
2. At each offset, take the **first** matching YES-token REST book whose request starts within `[start+offset, start+offset+60s)` and whose receipt precedes expiry. If missing, invalid, or reference inputs fail, SKIP that window/condition permanently; do not choose a later favorable decision book. Verify exact slug, condition, token, market opening and funded market status as of the event. No future book, candle, settlement or fast-reference observation may influence the decision.
3. Use the most recently **observed** Binance 1m/1h responses by that book receipt, at most 10s/120s old, and the 1m request start as the closed-candle availability boundary. Require 121 contiguous closed 1m candles and the currently forming candle. Recompute the frozen `HourlyPaper.probability`: zero-drift log-price diffusion, `sigma=stdev(120 log returns)`, `z=log(current/open)/(sigma sqrt(minutes remaining))`, `p_up=Phi(z)`. Verify the hour-open reference against the saved Limitless open. A candle fetched later than decision is unavailable even if its bar time is earlier.
4. Apply the unchanged original 3% contract buy fee, 3% hurdle, 10 USDC intended gross spend, six-decimal share rounding, full visible ask depth and maximum expected-edge side. Otherwise NO_TRADE. Use the first subsequent request for that slug starting after the 1.5s venue wait and before the decision's 30s expiry. Missing/error/late/invalid or insufficient first response permanently SKIPs; no midpoint fills or favorable retries. Settle hypothetical fill with the previously observed binary payout only for scored outcomes; no independent capital pooling across variants.
5. Report each window separately: decision/reference failure, no-trade, delayed skip, hypothetical fills, winners, settled PnL, fee-inclusive costs, full-condition Brier, UTC-hour clustering and profit concentration. The 30-minute strict-first protocol is **not** automatically identical to frozen hourly-v1, which could retry an earlier missing-frame input; verify matches and explain differences. Do not sum overlapping window variants as independent profit.

This comparison tests time sensitivity, not profitability. A positive old-window backtest remains exploratory; any time change would require a separately frozen forward paper phase. The result can falsify the specific windows but must not be used to pick a profitable minute on the already inspected sample.
