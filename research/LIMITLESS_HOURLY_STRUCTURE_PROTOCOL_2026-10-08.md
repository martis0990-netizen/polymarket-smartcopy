# Frozen diagnostic: closed-candle range break as one extra hourly factor

This protocol is written before evaluating the feature against binary outcomes or PnL. Research-only replay of the same SHA256-verified Limitless/Binance public hourly-v1 archives; no new capture, live orders, production model, fee, threshold or existing holdout changes. The October 6 holdout has already been repeatedly inspected, so it is exploratory for this new candidate.

1. Use precisely the **strict-first minute-30** conditions from `LIMITLESS_HOURLY_TIME_WINDOW_PROTOCOL_2026-10-07.md`: first book whose request starts within the 60-second window, verified exact YES token, FUNDED market and contemporaneous Binance 1m/1h responses. No later favorable input retry. On valid conditions use the saved `p_model` recomputed at that receipt and the contemporaneous YES best bid/ask midpoint `p_book` as **forecast only**. Missing reference, missing book or unresolved payout is unscored, not a negative trade.
2. Use only 121 contiguous fully closed Binance 1m candles available by both the source request start and decision receipt. Let `C` be the last closed candle's close. Let `H` and `L` be the maximum high and minimum low over the **60 candles ending 15 minutes before that last closed candle**: in zero-based Python notation `closed[-75:-15]` (60 candles). Assign `s=+1` if `C>H`, `s=-1` if `C<L`, otherwise `s=0`; equality is neutral. A last closed bar cannot satisfy both signs when `H>=L`. This is a local historical range-break proxy, **not** 4h Smart Money BOS/CHOCH or a stand-alone trade trigger. Do not inspect the current partial candle for `s`.
3. Chronologically before each decision at time `t`, fit the one convex baseline weight `w∈[0,1]` minimizing summed binary log loss of `q0=w·p_model+(1−w)·p_book` on earlier **eligible** decisions whose payout was observed strictly before `t`. If none, use `w=0.5`. Then fit one additional coefficient `β∈[-1,1]` by minimizing summed prior log loss of `sigmoid(logit(q0_prior)+β·s_prior) + 10·β²`. Each prior `q0_prior` is its **frozen prediction generated when that prior decision occurred**, never a retroactively refitted prediction. With no eligible settled prior training examples, use `β=0`. Report `q1=sigmoid(logit(q0)+β·s)`; clip probabilities to `[1e-6,1−1e-6]` only inside logit/logloss numerics.
4. Score q0 and q1, plus market-only and model-only, by full-condition Brier and log loss on identical observed outcomes, separately for discovery and previously inspected old holdout. Report nonzero feature counts and UTC-hour cluster score-difference uncertainty. No fee/PnL/entry gate is optimized or simulated here. Do not search alternative lookbacks, buffers, swing definitions, minute offsets or penalties after seeing results.

A directional improvement on this reused historical sample would still **not** establish a profitable strategy; execution economics and a new untouched forward phase would remain necessary. A null/negative result should be reported unchanged.
