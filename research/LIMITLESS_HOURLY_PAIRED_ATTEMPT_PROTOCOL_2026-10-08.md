# Limitless hourly paired second attempt: frozen retrospective protocol

Recorded before replaying second-leg attempts. This is a read-only, paper-only diagnostic of the existing 96 SHA256-verified main capture ZIPs and the previously published `limitless_hourly_event_trigger_2026-10-08.json`. The old holdout has already been inspected; no new independent validation is implied. The frozen hourly-v1 system, collection schedule, fees, entry hurdle, risk caps and production code remain untouched.

1. Keep exactly the 162 prior condition IDs, discovery/old-holdout labels, first qualifying opportunity, first delayed first-leg attempt, and first prospective opposite-side quote from the published event ledger. Do not reselect any first entry or second quote using later outcomes.
2. For each of the 60 rows with a successful first paper entry and an observed prospective paired quote, start the second action only after that quote's **receipt**. Use the same market venue wait `delay_s` from the saved hourly state (including its conservative extra 1 second), then take the **first** recorded REST book request for that exact slug whose request begins within the following 30 seconds. Include failed requests. Search across all 96 segments, sort by request start and stable provenance; do not retry after a failed/late/invalid/too-expensive first request.
3. The intended second gross quantity is exactly the prospective quoted quantity, chosen before the delayed request to match the first leg's net shares after the same frozen 3% contract buy fee. Require an observed funded market, valid exact YES token and both-sided book, request and receipt before expiry, full visible depth on the opposite ask, spend at most the unchanged 10 USDC leg budget, and `first_cost + delayed_second_cost < min(first_net_shares, delayed_second_net_shares)`. No midpoint, maker priority or hypothetical partial fill. The second fee is deducted from contracts. Report an unsuccessful second attempt as the original one-sided settled paper PnL, never as a free paired win.
4. For a successful delayed paper second leg, binary payout of the matched net shares is equal for either resolved outcome. Compute paired settled paper PnL = observed settlement payout for both legs minus both costs; separately report the implied paired minimum payout `min(net_shares)` and its conservative margin. Preserve settlement semantics from the original saved hourly evidence; do not infer settlement from later market quotes. No repeat entries, exits, merge, rebate, borrowing or reinvestment.
5. Verify every downloaded ZIP against the already published `archive_zip_digests` (96 IDs). Confirm the quoted second decision's original artifact, line and SHA256 and its as-of chronology in the capture stream. Retain first-attempt artifact/line/hash or explicit absence, status/reason, costs, net quantities, payout and UTC-hour cluster in machine rows. Report results by discovery and old holdout; never sum cumulative checkpoint reports or call a quote an actual fill.

Run on a temporary read-only GitHub Actions runner with `actions:read`, `contents:read`, artifact upload only. No external market request, credentials beyond the ephemeral Actions read token, signatures, or real orders. This is exploratory even if positive; the existing inspected holdout cannot certify profitability.
